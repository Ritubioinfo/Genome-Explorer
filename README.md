# 🧬 Genome Explorer

A beginner-friendly Python bioinformatics project for analyzing DNA sequences.

## 📌 About the Project

Genome Explorer is a command-line Python application developed to perform basic DNA sequence analysis.

The project was developed step-by-step, starting with basic Python concepts and gradually adding bioinformatics features.

## 🚀 Features

- DNA length calculation
- Nucleotide counting
- GC content calculation
- DNA validation
- Reverse DNA sequence
- Reverse complement DNA
- DNA to RNA transcription
- Start codon detection
- Stop codon detection
- Start codon position detection
- Interactive menu system

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code
- Basic bioinformatics concepts
